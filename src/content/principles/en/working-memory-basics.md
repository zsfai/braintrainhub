Think of working memory as a small desk: you hold materials there and process them at the same time. Capacity is limited; when interference piles up, the materials get knocked off.

## It Is Not the Same as “Poor Memory”

Everyday talk about memory often mixes long-term retrieval, attention, and emotional state. Working memory stresses **keeping and operating on information over the next few seconds to tens of seconds**. You might remember yesterday’s plot yet struggle to do mental math in a noisy room—the desk is full.

## What N-Back Trains

[N-Back](/en/tools/n-back/) asks you to continuously update “what was N steps ago,” forcing working memory to refresh and compare. It is a classic lab paradigm adapted into practice, useful for spotting error patterns as load rises. Treat it as **targeted practice**, not an “IQ supplement.”

## Pairing with Inhibitory Control

When the desk is taken up by irrelevant impulses, inhibitory exercises like [Stroop](/en/tools/stroop/) help you practice the sense of “seeing the pull without following it.” Combined with load-reduction tactics from [Cognitive Load](/en/principles/cognitive-load/), everyday tasks feel much lighter.
